# Queue

A Java console-based application that demonstrates the implementation of the Queue data structure using Linked Lists and Object-Oriented Programming. The project implements the fundamental Queue operations following the FIFO (First In, First Out) principle. Each use case is developed in a separate feature branch and merged into the development branch using a Git feature branch workflow.

---

## About the Project

A Queue is a linear data structure that follows the First In, First Out (FIFO) principle, where the first element inserted is the first one to be removed.

This project demonstrates how to implement a Queue using a Linked List in Java. It covers the core Queue operations such as enqueue (insertion) and dequeue (deletion) while maintaining FIFO ordering. The implementation follows Object-Oriented Programming principles and uses custom node structures instead of Java Collection classes.

## Git Workflow

The project follows a feature branch workflow.

- `main` – Initial project setup
- `dev` – Development branch
- `feature/UC1`
- `feature/UC2`

Each feature branch introduces a Queue operation. After implementation and testing, the feature branch is merged into the `dev` branch, ensuring incremental development and a clean Git history.
